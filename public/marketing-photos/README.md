# Fotos para Publicaciones (módulo /publicaciones)

Las plantillas de Instagram y LinkedIn referencian fotos desde esta
carpeta. Si no están, los templates renderizan con un gradient navy
de fallback — el preview funciona pero queda menos rico.

## Cómo agregar las fotos originales

Copiá los archivos del proyecto de Gabriel (`LDP Instagram Posts.html`
+ carpeta `photos/`) a esta carpeta, manteniendo los nombres exactos:

```
public/marketing-photos/
  firma-atlas.jpg
  oficina-pisapapeles.jpg
  oficina-pisapapeles-2.jpg
  oficina-membrete.jpg
  oficina-atlas.jpg
  oficina-grabados.jpg
  oficina-cuadros.jpg
  oficina-discobolo.jpg
  biplano-laton.jpg
  publicaciones-biblioteca-crop.jpg
  playa-caribe.jpg
  team-jorge.jpg
  team-katty.jpg
  team-perla.jpg
  team-gabriel.jpg
```

Una vez los archivos estén en su lugar, recargá la app — el módulo
las detecta automáticamente.

## Recomendaciones técnicas

- Resolución mínima: **1080×1350** (4:5) para posts. Stories
  necesitan **1080×1920**.
- Formato: JPG con calidad ~85% para que pesen poco sin perder
  detalle.
- Color: priorizá fotos con tonalidad cálida o navy oscuro para
  combinar con el frost glass.
